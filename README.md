# Расчет параметров прямоугольника и трапеции

Реализовать функци вычисления для следующих фигур:

Прямоугольник - периметр, площадь , длина диагонали;

Трапеция - периметр , площадь , длина средней линии.

## Описание 
Проект выполнен в рамках Лабораторной работы №1.


## Инструкция по сборке 

Для запуска понадобится компилятор `g++`.

```bash
g++ main.cpp -o rectangle.cpp -Iinclude
```
